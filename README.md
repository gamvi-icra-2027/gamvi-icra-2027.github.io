# GAMVI project page

Anonymous project page for **GaugeAware: Metric Visual–Inertial Camera Estimation for World-Grounded Human Motion (GAMVI)**. Static HTML/CSS/JavaScript; no build step or third-party runtime services.

Typography uses locally hosted Source Sans 3 Variable throughout the page. Main text is 21px on desktop and 19px on mobile; captions and protocol notes are 17px. Result tables use 18px values, 17px headers and 16px method notes, scrolling horizontally on narrow screens. The font is stored as WOFF2 without subsetting and distributed under the SIL Open Font License in `static/fonts/SourceSans3-OFL.txt`. The stylesheet URL is versioned to refresh previous cached typography, and no external font request is needed. Text embedded in existing plots/videos is unchanged by this stylesheet. Unused Inter and Lato files remain as design-history assets and retain their accompanying OFL license files.
